# 読書字幕 / Reading Subtitle — Android prototype v0.1

Kindle / Prime Reading などの洋書を読みながら、**ユーザーが許可した画面の英文をOCRで読み取り、画面下部に日本語字幕と簡易単語訳を表示する**Android用の実験プロジェクトです。著作権保護や画面キャプチャ禁止の回避はしません。

## できること

- `MediaProjection` を使い、OSが表示する画面共有の許可を取得
- `SYSTEM_ALERT_WINDOW` の許可を得て他アプリの上に下部字幕パネルを表示
- パネルの「読取」を押した時だけ、パネルを一時的に隠して画像を1フレーム取得
- Google ML Kit （端末内）の英語OCRで英文を抽出
- ML Kit English→Japanese 翻訳で最初の最大4文を訳す
- 英文から抽出した最大6語の**簡易訳**を併記（文脈を考慮した辞書ではない）
- 読取後は本文と字幕を並べて確認。パネルを縮小・終了可能
- メイン画面で英文を直接貼り付けて翻訳を検証可能
- `ACTION_SEND` の `text/plain` に対応（共有元アプリが対応する場合）

## 動作要件・ビルド

- Android 9（API 28）以上。Android 14/15/16 での実機動作は **未検証**
- Android Studio、JDK 17、Android SDK Platform 35、Gradle 8.11.1 以上（AGP 8.9.2）
- 依存ライブラリのダウンロードにインターネット接続が必要
- 本ZIPには**Gradle Wrapperの実行ファイルおよびAPKは同梱していません**。Android Studioでこのフォルダを開き、ローカルGradle 8.11.1+ を設定するか、対応するGradle環境で `gradle wrapper --gradle-version 8.11.1` を実行してラッパーを生成してください。
- Android Studioの「Build > Build APK(s)」またはGradleで `assembleDebug`。生成されたAPKは `app/build/outputs/apk/debug/` 以下。

## 操作

1. アプリを開いて「ほかのアプリの上に表示」権限を許可する。
2. 「画面共有を許可して字幕パネルを開始」を押す。Androidの画面共有許可画面で、利用できる場合は「画面全体」を選ぶ。
3. Kindleなど目的のアプリを開く。
4. 画面下部の「読取」を押す。パネルが一瞬隠れてOCR・翻訳が始まる。
5. 英文と日本語訳・単語の意味が下部に表示される。「読取」で次のページを再解析する。
6. 「終了」または通知の「終了」で画面共有を停止。
7. 電子書籍画面が取り込めない場合は、共有・コピーが許可された英文をメイン画面のテキスト欄に貼って試す。

初めて翻訳する時は、ML Kitの翻訳モデル（約30MB）がダウンロードされます。OCRのLatinモデルはアプリ内にバンドルされます。データをモバイル回線でダウンロードしたくない場合、Wi-Fi環境で初回起動してください。

## 重要な制限

- **Kindleでの動作は保証できません。** 対象アプリの `FLAG_SECURE` やDRMにより黒画面・取得不可となる場合があります。保護の回避は実装しません。
- **画面内の字幕表示が実機で動くか未検証です。** 端末・OS・選択された画面共有範囲で動作が異なります。特にAndroid 14以降は1回の同意につき1回の画面共有セッションです。
- OCRは最大約850字を対象にします。翻訳は最初の最大4セグメント（4文程度）まで。長文や複数カラム・縦書きへの対応は不十分です。
- 翻訳は機械翻訳であり、MorningEnglishの手作業校正済みチャンク対訳ほどの精度ではありません。単語訳は文脈非依存です。
- ページをめくっても自動追従しません。都度「読取」を押す設計です。
- 画面回転後はセッションを終了し、再度許可してください。
- 画面キャプチャとOCR本文はファイル・データベース・サーバーに保存せずメモリ内で処理。ML Kitの**初回モデルダウンロード**は通信します。
- この配布物は**ソースコードの試作**であり、APKビルド・実機検証は未実施です。

## 安全性

アプリはAccessibility Service、root、DRM回避、画面保護フラグの無効化、バックグラウンド自動スクレイピングを使いません。画面の共有範囲を利用者が決定し、OCRの実行も手動です。

## ファイル

- `app/src/main/java/jp/morningenglish/subtitle/MainActivity.java`: 権限と貼り付け翻訳テスト
- `app/src/main/java/jp/morningenglish/subtitle/OverlayService.java`: 画面共有・字幕オーバーレイ
- `app/src/main/java/jp/morningenglish/subtitle/ReadingEngine.java`: OCR・翻訳・語彙の抽出
- `preview.html`: 実アプリ連携なしのブラウザUIデモ（2ページのサンプル例文）
