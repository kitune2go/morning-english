# 『神々の対話』読解辞書・第2次意味監査

対象は Fowler 兄弟英訳のリポジトリ収録分、全19篇・238発言・585チャンク・8,612トークン（異なり語形1,752）です。

## 本次の変更

- 前回PR #21では29語の明確な誤訳を修正。今回の第2次監査では、単なる辞書訳の存在を超えて、本文の品詞・意味・神話固有名詞との一致を点検しました。
- 今回の修正：**119語形**。例：liver（肝臓）、Rhea（女神）、stole（盗んだ）、Atlas（巨神）、Argos（地名）、Paris（神話の王子）、quiver（矢筒）、Muses（前回修正）。
- 多義語は単一の誤訳で上書きせず、本文で確認できた用例と位置（Day番号）を note に明示しました。例：cross, light, bound（前回）。
- 本文の単語を他の見出し語に誤認した例、名詞と動詞を混同した例、神話固有名詞を現代の一般語義に置換した例を優先しました。
- `scripts/validate-books.mjs` に第2次意味回帰テストを追加しました。

## 検証の限界と継続方針

辞書の1,752項目は、もともと全8,612トークンを形式的にカバーしています。ただし『辞書に登録済み』と『原文のその箇所に正しい訳を選んだ』は別です。今回の修正は**誤りを確認できた語形に限定**しています。残る一般辞典由来の語形がすべて正しいと保証するものではなく、238発言・585チャンクの全文翻訳について専門家の逐語校閲が完了したことも意味しません。

次回以降は、読解時に同じ語が複数文脈で使われる箇所へ、段落・チャンク単位の文脈別訳を優先適用できる構造を検討してください。単語辞書そのものを一律の意味だけに固定すると、品詞・神話上の固有名詞・慣用句で誤りが再発します。
